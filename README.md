# Tidecraft — Cinematic website templates & prompts

A curated library of scroll-driven templates, components, shaders, sections
and UI screens with copy-paste rebuild prompts. Copy one, paste it into your
AI, and launch a site that moves.

Built with Next.js 16, React 19, Tailwind CSS v4, GSAP, Lenis and custom
WebGL shaders. All content is original.

## Run it

```bash
npm install
npm run dev
```

## Deploy

Push to GitHub — Vercel deploys automatically from `main`.
